# 📝 To-Do List Application

A full-stack **To-Do List application** built using **Node.js, Express, Supabase (PostgreSQL), and vanilla JavaScript**.  
The project supports complete **CRUD operations** and demonstrates real-world backend–frontend integration using cloud services.

---

## 🚀 Features

- ➕ Add new tasks
- 📋 View all tasks
- ✏️ Edit existing tasks
- ❌ Delete tasks
- ☁️ Cloud database using Supabase
- 🔐 Secure environment variable handling
- 🌐 RESTful API design
- 🎨 Clean UI using Bootstrap

---

## 🛠️ Tech Stack

### Frontend
- HTML
- CSS
- JavaScript
- Bootstrap 5

### Backend
- Node.js
- Express.js
- Supabase JavaScript Client

### Database
- Supabase (PostgreSQL)

### Deployment
- Backend: Render
- Database: Supabase Cloud
